## ⏱️ 100-Word Description

Designed a robust relational database schema utilizing MySQL, managed through Flyway for immutable schema evolution. Implemented secure, stateless Role-Based Access Control (RBAC) via JWT and silent refresh token rotation. The frontend features advanced state management using TanStack Query, React Hook Form for strict Zod validation, and route-based code splitting for sub-50ms load times. ## ⏱️ 200-Word Description
Lead the end-to-end architecture and development of an Enterprise Healthcare SaaS application designed to connect medical professionals with patients through an intuitive appointment scheduling interface. 

**Backend Engineering:** Developed a robust REST API using Java 17 and Spring Boot 3, strictly adhering to Clean Architecture and SOLID principles. Implemented a highly secure stateless authentication flow utilizing JWT, BCrypt password hashing, and a seamless refresh-token rotation strategy. Engineered complex JPA/Hibernate data models utilizing MySQL, protected against N+1 query inefficiencies through Entity Graphs, and fully version-controlled using Flyway migrations.

**Frontend Engineering:** Built a lightning-fast Single Page Application (SPA) using React 19, TypeScript, and Vite. Implemented a robust architectural pattern leveraging feature-based folder structures. Optimized network requests and global state via TanStack Query with custom caching strategies. Built complex, multi-step booking wizards using `react-hook-form` and `zod` for impenetrable client-side validation. Prioritized Web Vitals by implementing lazy loading, React Suspense, and esbuild chunk optimization, achieving exceptional Lighthouse performance scores.

**DevOps & QA:** Containerized the backend using Docker multi-stage builds. Established automated CI/CD pipelines via GitHub Actions to run JUnit 5 Integration Tests and Vitest/MSW frontend tests prior to automated deployments to Render and Vercel.

## 🏆 Key Achievements (Bullet Points for Resume)
- **Architected** an enterprise-grade full-stack healthcare application using Spring Boot and React 19, serving distinct portals for Doctors and Patients with strict Role-Based Access Control (RBAC).
- **Engineered** a secure, stateless authentication layer using JSON Web Tokens (JWT) with seamless refresh token rotation and BCrypt payload encryption.
- **Optimized** frontend performance achieving a 99/100 Lighthouse score by implementing route-based code splitting (React.lazy), TanStack Query caching, and Vite chunk optimization.

- **Automated** deployment workflows using Docker, GitHub Actions, and Vercel, integrating JUnit 5 and Vitest + MSW for comprehensive test coverage prior to release.
