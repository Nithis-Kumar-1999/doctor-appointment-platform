## Tips for High-Quality Captures
- **Use Mock Data**: Populate the database with realistic names (e.g., "Dr. Sarah Jenkins, Cardiology") instead of test data like "test1" or "doctorA".
- **Disable Extensions**: Turn off Grammarly or password manager extensions in your browser before taking screenshots to ensure clean UI elements.
- **Use a Wrapper**: Use a tool like [screely.com](https://screely.com) or [shots.so](https://shots.so) to wrap your screenshots in a sleek browser mockup window.
