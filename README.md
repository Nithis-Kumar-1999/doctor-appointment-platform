🏥 Doctor Appointment Management System
📌 Overview

A full-stack Doctor Appointment Management System that enables patients to search doctors, book appointments, and manage profiles, while doctors can manage availability and appointments.

Live Demo

🌐 Frontend: https://doctor-appointment-platform-kappa.vercel.app

📖 Swagger API: https://doctor-backend-f7nj.onrender.com/swagger-ui/index.html

🚀 Features:-

Authentication:
JWT Authentication,
Role-based Authorization (Doctor / Patient),
Secure Password Encryption (BCrypt),
Refresh Token Support

Patient:
Register & Login,
Search Doctors,
View Doctor Details,
Book Appointment,
View Appointment History

Doctor:
Login,
Manage Profile,
Manage Availability,
Accept / Reject Appointments,
View Dashboard,
